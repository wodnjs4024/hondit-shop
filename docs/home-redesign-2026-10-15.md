## 홈 구성

1. 첫 화면: 6초 제품 영상을 화면 폭 16:9로(1440에서 810px, 자르지 않음), 기존 승인 문구 + "상품 보기" + 해외 묶음 주문 링크. 모바일은 영상 → 문구 → 상품 보기(4:3, 좌우 여백만 잘림, 제품·상자 전체 보임)
2. 시장별 상품 줄: 실제 상품 사진, 이름·가격, 설명, 통화·MOQ, 해외 묶음 주문 버튼, 상세·Shopee
3. 제주: 숲 영상(반쪽, 문구 얹음) + 실제 StoneJeju 350g 사진(이름 표기). 모바일은 숲 영상만 세로로
4. 소재: 근접 영상을 화면 폭으로 + 사용 3단계
5. 350g·500g 비교: 규격별 실제 사진(350g 창가 컷, 500g 창가 컷)과 승인 사양·가격·MOQ·버튼
6. 구매: 실제 배송 사진 + 배송 안내 + 해외 묶음 주문·제주 수령·매장/사업자 경로, 기존 가격·MOQ 비교표
7. 홈 전용 헤더(PC 한 줄, 국가·언어는 하나의 버튼에서 선택), 푸터(판매자 정보 15px 이상), 모바일 하단바(첫 화면과 푸터에서는 숨김)

생성형 보조 이미지(`02_brand_lifestyle`)는 쓰지 않았고, 사진은 `01_product_originals`의 실제 제품 사진만 사용했습니다.
