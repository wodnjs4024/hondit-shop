## 발견과 수정
| 문제 | 영향 | 수정 |
| --- | --- | --- |
| 지도(OUR JEJU) 안에 클릭 가능한 지도 영역이 `role="img"` 안에 있음 | 스크린리더가 버튼을 못 찾음 | 지도 그룹을 `role="group"`으로 |
| 지도 단계 번호·보조 문구 대비 1.9~4.0:1 | WCAG AA 미달 | 4.5:1 이상 색으로 |
| 상단 공지가 랜드마크 밖 | 스크린리더 영역 탐색에서 누락 | 이름 있는 `aside`(6개 언어) |
| 상품 목록·문의·제주 수령에서 제목 단계 건너뜀(h1→h3) | 제목 탐색 순서가 끊김 | 숨김 h2 추가, 연락 채널 제목 h2로 |
| 지도 패널·상품 상세 영역이 중첩 랜드마크·같은 이름 랜드마크 | 탐색 혼동 | 일반 구역으로 |
| 상품 상세 사진 줄이 키보드로 스크롤 불가 | 키보드 사용자가 사진을 못 넘김 | 포커스 가능 + 포커스 표시 |
| 모바일 상품 상세: 사진이 첫 화면을 다 차지 | 가격이 첫 화면 끝에 걸침 | 사진 1:1, 가격이 첫 화면에(727→637px) |
| 모바일 주문서: 큰 상품 사진 때문에 입력이 늦게 시작 | 첫 입력칸 1774px, 결제 확인 3459px | 사진을 제목 옆 작은 썸네일로: 첫 입력칸 1451px, 결제 확인 3136px (각 약 320px 단축) |

이미 충족해서 그대로 둔 것: 주문서 입력칸의 라벨·자동완성(name·email·tel·address·postal-code)·숫자/이메일/전화 키패드·필드별 오류 표시, 영상 정지 버튼, 44px 터치 영역, 가로 스크롤 없음, 상세의 모바일 하단 주문 바.
