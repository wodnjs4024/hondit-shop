## 제품
직접 HTML과 상세 이미지를 읽어 상단 규격표·하단 사용법/주의사항을 시각 확인했다. 링크가 존재한다는 이유로 검증 완료 처리하지 않았다.
- [350g 공식 상세](https://stonejeju.com/product/detail.html?product_no=42): 유리용기 + 화산송이 + 시트러스 오일, 350g ±, 75(W)×100(H)×75(D)mm.
- [500g 공식 상세](https://stonejeju.com/product/detail.html?product_no=41): 제주옹기 + 화산송이 + 시트러스 오일, 500g ±, 100(W)×105(H)×100(D)mm.
- 상세 이미지 URL은 sources/image-urls.json에 기록. 오일 10mL는 기존 자료와 공식 상단 제품사진 병 표기를 대조했다.
- 두 이미지의 하단 사용 안내에서 1회 10~12방울, 필요 시 추가, 향 변경 전 온수 세척 후 완전 건조를 확인.
- 자연석 크기·색상 차이 및 미세 분말, 민감하거나 손상된 피부의 장시간 접촉 주의 안내를 반영.
- 국내 20,000원/50,000원은 확인했으나 해외 판매가격 데이터·카드·결제에 넣지 않았다.
- 상세 이미지의 FSC 문구는 다른 품목(치약) 설명이 섞여 있어 디퓨저 인증 근거로 재사용하지 않았다.
- 포장 크기·배송 총중량·기간·특정 국가의 운송/수입 승인은 위 규격과 무관하며 새로 확정하지 않음.

## 판매처
[공식 OFFLINESHOP](https://stonejeju.com/offlineshop.html)의 이미지 4줄 × 4개 장소를 읽어 16개를 추출했다. 상단 제주돌문화공원 중복 제거. 기타 공급처 기관 로고 6개는 매장으로 생성하지 않음.
- 전체 추출·검토 상태: sources/stockist-verification.json, sources/offlineshop-extraction.md.
- 8개 장소의 이름/주소 대조 자료를 확보해 공개 목록에 넣음. 5개 시설의 공개 지도 좌표만 마커 표시.
- 좌표 있는 곳: 제주돌문화공원, 9.81 PARK, 메종 글래드 제주, 만춘서점, 플레이스 캠프.
- 좌표 없는 공개 목록: 아라리오 동문모텔2, 더 아일랜더, 소길별하. 주소 자료만 사용하고 좌표를 생성하지 않음.
- 9.81은 공급사 이미지의 주소에서 누락된 애월읍을 공식 SPACECUP 주소와 공개지도에서 보완.
- 메종 글래드/돌문화공원/플레이스 캠프 좌표는 시설 기준. 개별 기프트샵 내부 위치를 확정한 것은 아님.
- 공식 관광공사 지도/공식 사업장 페이지/협력사 공개 자료를 locationSourceUrl로 기록. 개별 방문 운영·현재 취급 SKU·재고는 전부 미확인.
- 8개 공개 제외: 제주맥주 기프트샵, 블루보틀 제주맥주 코너샵, 한화 스페테라피 센터, 신화테마공원 기프트샵, 성이시돌 센터, 사계생활, 돗돗헌, 제주규리.
- 신화월드: 공급사 테마공원 주소 304번길 139와 현 공식 리조트 대표 주소 304번길 38이 달라 임의 통합하지 않음.
- 성이시돌: 연결 공식 페이지가 피정의집으로, 등록 센터 위치와 동일성을 확정할 수 없음.
- 제주맥주 공식 채널 502, 사계생활 공식 채널 접근 실패. 나머지 제외 장소도 현재 운영/주소 대조가 충분하지 않음. 폐업이라고 단정하지 않음.
- 장소 사진은 사용 범위 미확인으로 전부 비공개. 원본 분석용 캡처는 로컬에만 보관하고 커밋·정적 사이트에서 제외.
