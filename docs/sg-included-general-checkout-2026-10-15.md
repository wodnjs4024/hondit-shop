# SG 디퓨저 배송비 포함 일반 주문 — 로컬 적용 결과

작성일: 2026-10-15 · 브랜치: `codex/checkout-flow` · 시작 커밋: `dba3312`

이 보고서는 앞선 `quantity-checkout-2026-10-15.md`의 SG 21개 이상 견적 제한을 **사용자의 최종 배송비 포함 판매정책**으로 대체한다. 과거 보고서와 주문 기록은 변경하지 않는다.

## 확정 정책 및 결과
| 수량 | 350g 최종 결제금액 | 500g 최종 결제금액 | 동작 |
|---|---:|---:|---|
| 10개 | SGD 230 | SGD 500 | 직접결제 |
| 15개 | 해당 없음 | 해당 없음 | 입력은 보존, 진행 차단 |
| 20개 | SGD 420 | SGD 920 | 직접결제 |
| 21개 | SGD 441 | SGD 966 | 직접결제 |
| 35개 | SGD 735 | SGD 1,610 | 직접결제 |
| 100개 | SGD 2,100 | SGD 4,600 | 직접결제 |

10개 체험은 고정 최종가격, 일반 주문은 20~9,999 사이 정수에 350g 2,100센트/500g 4,600센트를 곱한다. 실제 주문 가능 최대 수량은 상품 활성 여부·재고 검증으로 제한한다. 국제배송비 추가 청구는 0이다. 운임 비례 추정이나 새 할인은 없다. 실제 운임과 추정 운임 차이는 판매자 부담이다. 세금·통관비의 기존 수취인 부담 정책은 유지한다.

## 수정 파일과 공통 계산
- `shared/checkout-terms.js`: SG 두 디퓨저의 20~9,999개 배송비 포함 범위 및 새 조건 버전 `sg-general-delivered-2026-10-15`, 배송 버전 `sg-general-included-2026-10-15`. 다른 시장 조건과 클렌징 조건은 변경하지 않음.
- `shared/page-sales.js`, `shared/purchase-context.js`: 기존 구매 검토 헬퍼의 SG 20개 한정 판단을 이번 정책에 맞춰 수정. 다른 시장과 혼합 주문의 기존 동작 유지.
- `shared/shipping-summary.js`, `shared/structure-copy.js`, `src/pages/BulkOrdersPage.tsx`: 상품별 및 일반 배송 안내의 이전 20개 한정 문구 수정. 기존 지원 언어 번역 연결.
- `tests/delivery-charge.test.mjs`, `tests/diffuser-quantity.test.mjs`, `tests/sales-structure.test.mjs`, `tests/sales-tools.test.mjs`: 새 정책 및 기존 제한에 대한 회귀 테스트.

상품 상세의 QuantityReview, 해외 주문, 재판매 계산기는 기존 공통 조건을 사용한다. PayPal 생성 서버도 동일한 resolveCheckoutCart를 사용하여 DB 상품·수량·재고를 재검증하고 승인 단가로 최종금액을 계산한다. 고객이 제출한 가격·금액·승인 상태는 계산 원본으로 쓰지 않는다. 포함 운임을 다시 더하지 않는다.

새 주문의 기존 조건 스냅샷에 새 버전·수량·상품금액·배송비 0·청구통화를 남기는 구조를 유지한다. Capture의 주문 연결, 청구금액·통화·주소 확인과 완료 결제 재요청 보호는 변경하지 않았다. 과거 주문의 가격과 조건은 재계산하지 않는다.
